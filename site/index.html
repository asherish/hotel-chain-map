    About the data

    This map shows hotel locations of a few major chains, as published by the All the Places open-data project (GitHub). All the Places is maintained by volunteers who write and maintain the web spiders that collect this data — thank you! The data is published under CC0.

    Locations come from each brand's own website, via All the Places. The data may be incomplete or out of date, and this map does not fix or verify it. This project is not affiliated with, or endorsed by, any hotel company.

    Found a wrong or missing hotel? Please report it upstream on the All the Places issue tracker, mentioning the spider that produced it. The spider for each chain is listed below and in meta.json; spider sources live under locations/spiders/ in the All the Places repository.

      Basemap tiles by OpenFreeMap, data from OpenStreetMap contributors. Map issues (not data issues) can be reported at this project's issue tracker.
